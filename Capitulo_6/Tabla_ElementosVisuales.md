# Tabla de ayuda — Elementos visuales de [Microsoft Power BI]

<br/><br/>

| Nombre en inglés       | Nombre común en español       | Descripción breve                                           |
| ---------------------- | ----------------------------- | ----------------------------------------------------------- |
| Card                   | Tarjeta                       | Muestra un único KPI o valor destacado.                     |
| Multi-row Card         | Tarjeta de varias filas       | Presenta varios indicadores resumidos.                      |
| Table                  | Tabla                         | Muestra datos tabulares detallados.                         |
| Matrix                 | Matriz                        | Similar a una tabla dinámica con jerarquías y subtotales.   |
| Clustered Column Chart | Gráfico de columnas agrupadas | Compara categorías mediante columnas verticales.            |
| Clustered Bar Chart    | Gráfico de barras agrupadas   | Compara categorías usando barras horizontales.              |
| Stacked Column Chart   | Gráfico de columnas apiladas  | Muestra composición y acumulación de valores.               |
| Stacked Bar Chart      | Gráfico de barras apiladas    | Representa proporciones de manera horizontal.               |
| Line Chart             | Gráfico de líneas             | Ideal para mostrar tendencias en el tiempo.                 |
| Area Chart             | Gráfico de áreas              | Similar al gráfico de líneas, resaltando volumen acumulado. |
| Combo Chart            | Gráfico combinado             | Combina líneas y columnas en un solo visual.                |
| Pie Chart              | Gráfico circular o pastel     | Representa participación porcentual.                        |
| Donut Chart            | Gráfico de dona               | Variante del gráfico circular con centro vacío.             |
| Treemap                | Mapa de árbol                 | Muestra proporciones mediante rectángulos.                  |
| Scatter Chart          | Gráfico de dispersión         | Analiza relación entre variables numéricas.                 |
| Bubble Chart           | Gráfico de burbujas           | Variante de dispersión con tamaño adicional por valor.      |
| Funnel                 | Embudo                        | Representa etapas de un proceso o conversión.               |
| Waterfall Chart        | Gráfico de cascada            | Visualiza incrementos y decrementos acumulados.             |
| Gauge                  | Medidor                       | Muestra avance respecto a un objetivo.                      |
| KPI                    | Indicador KPI                 | Resume desempeño usando métricas y tendencia.               |
| Slicer                 | Segmentador de datos          | Permite filtrar otros visuales del dashboard.               |
| Map                    | Mapa                          | Visualiza información geográfica.                           |
| Filled Map             | Mapa relleno                  | Colorea regiones según valores.                             |
| ArcGIS Maps            | Mapas ArcGIS                  | Mapas avanzados con capacidades GIS.                        |
| Ribbon Chart           | Gráfico de cintas             | Muestra cambios de ranking a lo largo del tiempo.           |
| Decomposition Tree     | Árbol de descomposición       | Analiza causas y desglose jerárquico de métricas.           |
| Key Influencers        | Influenciadores clave         | Detecta factores que impactan un resultado.                 |
| Q&A Visual             | Preguntas y respuestas        | Genera visuales usando lenguaje natural.                    |
| Heat Map               | Mapa de calor                 | Representa intensidad mediante colores.                     |
| Custom Visual          | Visual personalizado          | Visual desarrollado por terceros o la comunidad.            |


<br/><br/>

## Recomendaciones rápidas

| Necesidad                                | Visual recomendado     |
| ---------------------------------------- | ---------------------- |
| Mostrar un KPI único                     | Card                   |
| Comparar categorías                      | Clustered Bar / Column |
| Ver tendencias                           | Line Chart             |
| Analizar correlación                     | Scatter Chart          |
| Filtrar dashboard                        | Slicer                 |
| Mostrar detalle tabular                  | Table / Matrix         |
| Ver participación porcentual             | Pie / Donut            |
| Analizar geografía                       | Map                    |
| Ver contribuciones positivas y negativas | Waterfall              |
| Analizar etapas de proceso               | Funnel                 |
